How a launch is priced

Launch value is the market cap a protocol's token could carry: log10(cap) is fitted on log10(TVL) across protocols whose token trades, one row per ticker. Each extra term (category, age, growth, chains) is kept only if it lowers the held-out miss in both a leave-one-out and a walk-forward test.

Token odds is the chance that a protocol like it ever records a token: a logistic regression fitted by gradient descent on its peers, on how long it has run with no token, its 7-day TVL growth and its category.

Implied value = launch value x odds. A protocol records no token in DefiLlama's data; that is the entry's own estimate, not a prediction of when or whether one is issued. Gas figures per chain are stated assumptions.
